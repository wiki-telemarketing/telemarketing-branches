# Справочник отделений для GitHub Pages

GitHub Actions читает вкладку «Переезды» в Google Таблице, преобразует данные и публикует статический сайт. В опубликованные файлы попадают поля карточек и пометки о переездах и письмах. Исходный XLSX, внутренние номера и полные тексты служебных комментариев в публикацию не входят.

## Подключение

1. Добавьте файлы в выделенный репозиторий с основной веткой **main**.
2. В **Settings → Secrets and variables → Actions** создайте секрет **MGKL_SOURCE_XLSX_URL**. Значение должно быть ссылкой на XLSX-экспорт вкладки «Переезды» по шаблону https://docs.google.com/spreadsheets/d/ID/export?format=xlsx&gid=GID.
3. В **Settings → Pages → Source** выберите **GitHub Actions**.
4. Запустите **Publish directory to GitHub Pages** на вкладке Actions. Адрес опубликованной страницы появится в задаче **deploy**.

## Обновление

Расписание задано на каждые 15 минут. GitHub может задерживать запуски. При неудачной сборке предыдущая публикация продолжит открываться. Если с последней успешной загрузки прошло более 45 минут, справочник помечает данные как сохранённую копию. GitHub может отключить расписание публичного репозитория после 60 дней без активности.

Карта использует OpenStreetMap. Поиск произвольных адресов использует Photon. Маршруты открываются в Яндекс Картах.
